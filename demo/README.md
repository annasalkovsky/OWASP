# OWASP Dependency Audit Tool - Interactive Demo

## 🎬 Demo Overview

This interactive HTML presentation showcases the OWASP Dependency Audit Tool with:

- **7 Engaging Slides** with smooth transitions
- **Auto-play functionality** (5 seconds per slide)
- **Interactive controls** for navigation
- **Keyboard shortcuts** for easy control
- **Responsive design** for all devices

## 🚀 How to View

1. **Open the demo**: Double-click `demo/index.html` in your file explorer
2. **Or serve locally**: Use any web server to host the demo folder

## 🎮 Controls

### Navigation
- **Next/Previous buttons** at the bottom
- **Arrow keys** (← →) for navigation
- **Spacebar** to advance slides
- **Home key** to restart
- **P key** to toggle auto-play

### Features
- **Auto-play toggle** in top-right corner
- **Progress bar** at the top
- **Slide counter** in each slide
- **Restart button** to begin again

## 📋 Slide Content

1. **Opening Hook** - Tool introduction with key features
2. **Upload Process** - Simple file upload workflow  
3. **Security Dashboard** - Beautiful vulnerability metrics
4. **Delta Mode** - Comparison feature introduction
5. **Delta Results** - Fixed vs new vulnerabilities
6. **Export Features** - Sharing and export capabilities
7. **Call to Action** - GitHub links and getting started
